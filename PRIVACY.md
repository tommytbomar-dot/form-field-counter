# Privacy

Form Field Counter reads the structure of the page in the active tab only when you click the toolbar icon.
It counts form fields. It does not read what you typed, does not send any data anywhere, has no analytics, no network requests, and no background process.
Permissions: `activeTab` (only the tab you clicked on) and `scripting` (to run the counting function in that tab).
